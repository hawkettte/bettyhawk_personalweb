# Betty Hawk — Personal Brand Website

Professional personal-brand site built with Next.js and deployed via Vercel.

## Development

```bash
npm install
npm run dev
```

Visit http://localhost:3000.

## Deploy to Vercel

1. In Vercel, choose **Add New → Project** and import `hawkettte/bettyhawk_personalweb`.
2. Vercel should automatically detect Next.js. Use default build settings and deploy.
3. Once ready, add your Cloudflare-managed domain in Vercel Project → Settings → Domains.
4. Set the exact DNS records Vercel requests in Cloudflare. Keep the domain at Cloudflare; no transfer required.

## Before public launch

- Replace the generic LinkedIn URL with Betty's actual profile.
- Review and approve all professional experience claims.
- Add an approved headshot and résumé (no files or private contact details are published yet).
- Confirm metadata and chosen domain.

No secrets or API credentials are required for this static site.
